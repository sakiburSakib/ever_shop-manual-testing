# Ever Shop – Web Application Testing

Manual QA testing of the [Ever Shop](https://demo.evershop.io/) e-commerce web application, focusing on search functionality, shopping cart, UI behavior, and API testing.

## Testing Scope
- Manual Testing
- Functional & Negative Testing
- UI Testing
- API Testing using Postman
- Test Case Execution
- Defect Reporting

## Project Deliverables
- **Test Cases:** Test scenarios, preconditions, steps, and expected results.
- **Test Execution:** Actual results and Pass/Fail status.
- **API Testing:** API requests and response validation.
- **Defect Log:** Identified issues with severity and supporting evidence.
- **Test Report:** Summary of findings and recommendations.

## Tools Used
- Google Chrome
- Postman
- Microsoft Excel
- Microsoft Word

## Test Summary
Testing covered product search, product selection, cart operations, and API behavior. Issues were identified in search functionality and product retrieval through API requests.
